# Engine, tools, and tests (loads when you open one)

Gotchas first; they are the part that has cost something.

- **Reproduce before fixing.** Run the filed reproduction as a scratch script in `tools/_scratch_<tag>/` before touching code, print the buggy and the correct value side by side, then re-run after. On 2026-08-05 this corrected the diagnosis of all six items landed (R55, R56, R57, R59, R65, R98(a)): the cited line was inert, the crash condition was different, the "existing import" did not exist. When an entry cites a line AND quotes an observed field, verify the line writes that field.
- **Mutation-check every new test by hand.** Revert the fix, run the test, expect red, restore. Five of the first hand-run mutations survived: a guard split across two pinned units with an unpinned join, a frozen clock equal to the real date, an assertion satisfied by the other branch's message, and in-process state the suite had already dirtied (anything asserting on import graphs, env vars, or module caches runs in a subprocess). A test that runs the production function beats a string pin on source (R300).
- **Grep the class, and put the enumeration in the CHANGELOG entry (R233).** A fix that closes N named sites usually has an N+1th; the R289/R291 `Excluded` column had two named stamp sites and five real ones. A deliberately kept copy is named with its reason.
- **A gate fix reddens fixtures, and that is the fix working.** Make the fixture declare `assume_gates` (or `RunSlateFrontDoorTests.UNEVIDENCED`) with a comment saying what it cannot evidence; never loosen the gate or synthesize data to get green (R53 lineage). If a genuinely evidenced build fails, the gate is too strict, which is a different conversation.
- **No test may depend on Ben's disk (R155, R62(a)).** `data/reference/` and `data/archive/2026-06-03/` are vendored; everything under gitignored paths is guarded with a skip that names the constant. A data path reached through production code is invisible to the vendored-or-guarded AST check, so ask which machine the path exists on; when a tool derives its root from `__file__`, copy it into a temp skeleton and run the copy. Verify on a clone, not the working tree.
- **Test pins.** `EXPECTED_SUITE_COUNTS` in `tools/audit.py`, one comment line per move: `R###, date: old -> new, the N that pin X`. A new module moves the filesystem module count by itself. `test_greenfield_regressions` and `test_production` are pytest suites run whole (`PYTEST_SUITES`); `unittest` collects nothing from them.
- **Refusals are a table.** `REFUSAL_SITES` in `skills/generate-lineups/scripts/build_slate.py`: every refusal payload carries the slate date, a class, an exit code, and an `authority` (`claude_md_wall`, `dk_rule`, `search_effort`). The crosswalk wall is CLAUDE.md's, not DK's. Exit 10 (bank thin) is a refusal too.
- **Intake.** The schedule hydrate stops carrying a game's lineup once it starts, so after first pitch "confirmed" comes from `observed_starter_state` (three values: `started`, `did_not_start`, `unobserved`; never a bool) and an empty boxscore block is `sides_unread`, never nine scratches (R270; R279 open). `merge_dk_starting_into_feed` only adds or upgrades a side and never backfills `game_date_utc` (R346 open). FanGraphs returns 403 to urllib and 200 to curl (R317).
- **Determinism.** `stable_union`, sorted inputs, `PYTHONHASHSEED=0` at entry points. A time-limited incumbent is verified against the constraint matrix and tagged `optimality='time_limited'`; a timeout never climbs the overlap ladder or enters `attempted` in the bank cache. The allocator says "time limit at gap X" or "proven infeasible: <constraint>", never both.
- **No call budget is the engine's.** `solver_probe.DEFAULT_BUDGET_S` and `audit.GATE_DEFAULT_BUDGET_S` are RESOLVED per host from `repo_env.call_budget_s()` (R349, R358), not constants: ~630s in a cloud container, 130s on Cowork and for a host that states nothing. Never pin a test to a host's number, and never reintroduce a literal.
- **Hosts.** DEV runs in a cloud container (bash) or on Ben's Windows machine (PowerShell). Anything a DEV session will run is a `python` entry point, because `TZ=... date`, `nohup` and `setsid` are bash-only. `docs/hosts.md` has what each host supports. Paths in tests go through `Path`, never string concatenation.
- **Surgical changes.** Touch only what the item names; match the surrounding style; do not refactor adjacent code or delete dead code you happened to find (file it instead). The engine's behavior is pinned module by module, and a golden replay (`tests/golden/`) freezes the production build; a re-freeze is a deliberate act recorded in the CHANGELOG with the histogram before and after.
