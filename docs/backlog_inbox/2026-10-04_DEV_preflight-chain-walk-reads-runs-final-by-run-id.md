# 2026-10-04 DEV (Session 142, R473): the preflight's supersession-chain walk falls back to `runs/<row.run_id>/final/DKEntries.csv` as the parent's bytes

**Observed.** `tools/preflight_upload.py` (`:1773-1776` at c2979af, in the function that finds the parent of a delivered file by the manifest's `superseded_by` chain) tries two candidates for the superseded record's bytes: `REPO_ROOT / rec["delivered_file"]`, then `REPO_ROOT / "runs" / rec["run_id"] / "final" / "DKEntries.csv"`. The second assumes the row's run holds the row's bytes. That is false for a row recorded under a run's id for other bytes (1400_4g: variant 7fdaa380 under run 0efaf97e; R430 refuses the same-tag case now, and another slate tag, a lost parent record, or a legacy manifest still produce it). If such a variant row's delivered file is gone from disk, the walk reads the run's own export as the variant's bytes, and the locked-slot preservation check then compares a child against the wrong parent, with `parent_source` saying it came from the manifest supersession chain.

**How it was found.** The `dfs-premise` agent's enumeration of every reader that selects a row or record by `run_id` alone, for R473 (Session 142), classified this one "mild, same class". R473 fixed the three readers on the re-promotion and late-swap paths; this one is on the preflight path and was left alone (surgical, and a V-gate file).

**Candidate item.** Take the run's export as the fallback only when `sha256_file` of it equals `rec["sha256"]`; otherwise warn that the parent's bytes are unavailable (the existing "neither is the run snapshot" branch already says locked-slot preservation is unverified). Test: a chain whose superseded row names run R, has no file on disk, and whose `runs/R/final` has other bytes warns and returns None. No incident is recorded from this. The one real run on this host whose manifest rows carry two shas, `20260728T221859Z_7567b76a`, has both rows under one slate tag and one delivered path; whether its chain reaches this fallback was not traced.
