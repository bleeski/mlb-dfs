### E-A (effort S-M, benefit highest). One deterministic pre-upload gate: `tools/preflight_upload.py`

- **Rationale:** the user asked for a QA process that checks lineups make sense, land in the right contest, and start no IL players — without process weight. Today those checks are scattered across `verify_classic` (script-internal), `verify_export.py` (weaker, identity-blind), the certifier (per-path), and vibes. The fix is one command, pure CSV+JSON reads, sub-5-seconds, run as the single ritual between "build finished" and "Ben uploads": that is a verification loop in the Anthropic sense — the manual check encoded so every session applies it identically.
- **Sketch:** `python tools/preflight_upload.py --date 2026-07-25 [--file <csv>]` reads the upload manifest (N-4), the delivered file(s), the parent DKEntries, the freshest lineups feed, and the salary CSV, and emits PASS/FAIL per file with named reasons: (1) geometry matches declared contest type (N-2); (2) every Entry ID present exactly once, zero blank reserved rows; (3) contest IDs match the manifest and the parent CSV (N-4/N-10); (4) full DK legality per type — salary cap, slots, 5-hitter, 2-game, opposing-SP, CPT pricing recomputed (N-6); (5) roster-status screen — no `Status in {IL,O,OUT}` player, every rostered player present in his team's posted lineup or probables when that team has posted, named WARN for DTD (N-3); (6) sha256 matches the brief; (7) clock — no player whose game is already locked unless the file came from late swap. Exit 0 clean, 2 warnings-only, 3 hard fail. The generate-lineups skill runs it automatically at the end of every build and prints the one-line verdict (embedded verification); Ben can also run it standalone on any file he is about to touch.
- **Why it will not cause paralysis:** every check is a read of files already on disk; there is nothing to break upstream; hard-fail is reserved for the five things DK or the bankroll cannot forgive (wrong contest, illegal roster, blank row, IL starter, locked game), and everything else is a warning that prints and ships.
- **Acceptance:** the tool catches, on fixtures: a Showdown file declared Classic, a swapped contest ID, a 6-hitter stack, an IL starter, a blank row, a stale sha256 — and passes today's real certified Classic file. SKILL.md's "verifying a file you did not just build" section points at it and nothing else.
